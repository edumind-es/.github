# Release de código abierto

Este repositorio es la *release* pública de MathBlast! 2.0.

- Es una app 100 % estática: todo el código que se ejecuta está aquí.
- No contiene secretos, claves ni configuración de despliegue.
- No contiene ni recoge datos de alumnado ni de docentes.
- Los problemas y ejemplos usan nombres ficticios.
