# Contribuir a EDUmind

Gracias por tu interés. Estos repositorios son releases públicas de apps en producción educativa real.

## Cómo contribuir

1. Abre un *issue* describiendo el problema o propuesta antes de enviar código.
2. Para cambios de código: fork → rama descriptiva → pull request pequeña y enfocada.
3. Los commits, en español y descriptivos.

## Requisitos de las contribuciones

- El código aportado se licencia bajo el esquema del repo: **AGPL-3.0-or-later OR EUPL-1.2**.
- Sin datos personales (ni de alumnado ni de docentes) en código, tests o fixtures.
- Sin secretos ni configuración de despliegue.
- La marca EDUmind® no forma parte de la licencia (ver TRADEMARKS.md).

## Seguridad

No abras issues públicos para vulnerabilidades: ver [SECURITY.md](SECURITY.md).
